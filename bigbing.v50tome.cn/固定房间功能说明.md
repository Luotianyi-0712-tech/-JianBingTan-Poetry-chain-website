# 固定房间功能说明

## 功能概述

本次更新为煎饼摊诗词接龙网站添加了**固定房间（共享空间）**功能，包括6个永久开放的固定房间，以及一个浮动菜单系统。

## 新增功能

### 1. 浮动菜单按钮
- **位置**：屏幕右下角
- **图标**：✉ 信封图标
- **功能**：点击后从右侧弹出黑色侧边栏菜单

### 2. 侧边栏菜单
- **第一项**：共享空间 - 点击跳转到 `/Sharedroom` 页面
- **其他四项**：功能预留位置（显示为"功能2-5（敬请期待）"）

### 3. 共享空间页面 (`/Sharedroom`)
展示6个固定房间，每个房间都有：
- **房间码**：100001-100006
- **主题名称**：
  - 100001：春之庭 🌸
  - 100002：夏之苑 🍃
  - 100003：秋之阁 🍂
  - 100004：冬之轩 ❄️
  - 100005：月之榭 🌙
  - 100006：日之台 ☀️
- **实时统计**：显示当前在线人数和诗词数量
- **进入按钮**：点击直接加入对应房间

### 4. 固定房间特性

#### 4.1 永久保留
- 固定房间不会被12小时自动清理机制删除
- 即使房间内没有玩家，房间也会保留
- 服务器重启后会自动初始化这些房间

#### 4.2 权限限制
- **普通用户**：
  - ✅ 可以加入固定房间
  - ✅ 可以添加诗词
  - ✅ 可以查看房间内容
  - ❌ **不能重置游戏**（重置按钮被禁用）
  
- **管理员**：
  - ✅ 拥有所有普通用户权限
  - ✅ 可以重置固定房间
  - ✅ 可以在控制台手动清空固定房间

#### 4.3 UI标识
- 固定房间在房间码旁边显示 "🏛️固定" 标识
- 非管理员用户的重置按钮显示为灰色且不可点击
- 鼠标悬停在禁用的重置按钮上会显示提示信息

## 技术实现

### 后端修改 (`app.py`)

1. **新增固定房间常量**
```python
FIXED_ROOMS = ['100001', '100002', '100003', '100004', '100005', '100006']
```

2. **新增辅助函数**
- `is_fixed_room(room_code)`: 检查是否为固定房间
- `initialize_fixed_rooms()`: 初始化固定房间
- 修改 `cleanup_inactive_rooms()`: 跳过固定房间的清理
- 修改 `leave_room_by_code()`: 固定房间即使无人也不删除

3. **新增路由**
- `GET /Sharedroom`: 共享空间页面
- `GET /api/shared_rooms/stats`: 获取固定房间统计信息

4. **修改权限控制**
- `POST /api/reset/<room_code>`: 固定房间只允许管理员重置
- `POST /api/admin/delete_room`: 固定房间只能清空内容，不能删除

### 前端修改

1. **HTML** (`templates/index.html`)
- 添加浮动菜单按钮
- 添加侧边栏菜单结构

2. **CSS** (`static/style.css`)
- 浮动按钮样式（圆形、渐变背景、悬停效果）
- 侧边栏样式（黑色主题、滑入动画）
- 响应式设计（移动端适配）

3. **JavaScript** (`static/script.js`)
- `initFloatingMenu()`: 初始化菜单交互
- `checkAndUpdateFixedRoomUI()`: 检测固定房间并更新UI
- 禁用非管理员的重置按钮
- 添加固定房间标识

4. **新页面** (`templates/sharedroom.html` + `static/sharedroom.css`)
- 展示6个固定房间的卡片式布局
- 实时显示房间统计信息
- 美观的国风设计

## 使用说明

### 普通用户
1. 点击右下角的 ✉ 按钮打开菜单
2. 点击"共享空间"进入固定房间列表
3. 选择任意房间点击"进入房间"
4. 在固定房间中可以正常添加诗词，但无法重置游戏

### 管理员
1. 可以像普通用户一样使用固定房间
2. 在固定房间中可以点击"重置游戏"按钮清空房间内容
3. 在管理员控制台（房间207128）可以查看所有房间，包括固定房间
4. 通过管理员控制台删除固定房间时，只会清空内容，不会删除房间本身

## 与原有功能的兼容性

✅ **完全兼容**：所有修改都不影响原有游戏功能
- 普通房间的创建、加入、游戏流程完全不受影响
- 12小时清理机制只针对普通房间，不影响固定房间
- 管理员房间（207128）功能保持不变
- 所有原有的游戏规则和交互保持不变

## 数据持久化

- 固定房间数据保存在 `rooms_data.json` 中
- 服务器启动时自动检查并初始化固定房间
- 如果固定房间已存在，保留原有数据
- 如果固定房间不存在，创建空房间

## 注意事项

1. **首次部署**：服务器启动后会自动创建6个固定房间
2. **数据备份**：建议定期备份 `rooms_data.json` 文件
3. **管理员权限**：只有用户名为"管理员"的用户才能重置固定房间
4. **浏览器兼容性**：建议使用现代浏览器（Chrome、Firefox、Safari、Edge）
