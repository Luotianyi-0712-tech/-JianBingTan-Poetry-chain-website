# 🚀 煎饼摊诗词接龙游戏 - 宝塔部署详细说明

## 📋 部署前准备

### 1. 系统要求
- 操作系统：CentOS 7+ / Ubuntu 18+ / Debian 9+
- 宝塔面板：7.0+
- Python版本：3.8+
- 内存：建议2GB+
- 磁盘空间：至少1GB可用空间
- **新增要求**：支持WebSocket连接（用于实时协同编辑）

### 2. 宝塔面板安装
如果还没有安装宝塔面板，请先安装：
```bash
# CentOS
yum install -y wget && wget -O install.sh http://download.bt.cn/install/install_6.0.sh && sh install.sh

# Ubuntu/Debian
wget -O install.sh http://download.bt.cn/install/install-ubuntu_6.0.sh && sudo bash install.sh
```

## 🛠️ 详细部署步骤

### 第一步：上传项目文件

1. **下载项目文件**
   - 将整个项目文件夹下载到本地
   - 确保包含以下文件：
     ```
     app.py              # Flask主应用
     requirements.txt    # Python依赖
     bt_config.py        # 宝塔配置
     start.sh           # 启动脚本
     templates/          # HTML模板目录
     static/            # 静态资源目录
     README.md          # 项目说明
     ```

2. **上传到服务器**
   - 在宝塔面板中创建网站
   - 将项目文件上传到网站根目录
   - 或者使用FTP/SFTP工具上传

### 第二步：安装Python环境

1. **在宝塔面板中安装Python**
   - 打开宝塔面板 → 软件商店
   - 搜索"Python项目管理器"
   - 点击安装

2. **创建Python项目**
   - 在宝塔面板中点击"Python项目"
   - 点击"添加Python项目"
   - 填写项目信息：
     - 项目名称：`jianbing-game`
     - 项目路径：选择网站目录
     - Python版本：选择3.8+
     - 项目端口：`5000`
     - 启动文件：`app.py`

### 第三步：安装项目依赖

1. **SSH连接到服务器**
   ```bash
   ssh root@你的服务器IP
   ```

2. **进入项目目录**
   ```bash
   cd /www/wwwroot/你的网站目录
   ```

3. **安装依赖**
   ```bash
   pip3 install -r requirements.txt
   ```

4. **如果遇到权限问题，使用sudo**
   ```bash
   sudo pip3 install -r requirements.txt
   ```

5. **验证WebSocket支持**
   ```bash
   # 检查eventlet是否安装成功
   python3 -c "import eventlet; print('eventlet安装成功')"
   
   # 检查Flask-SocketIO是否安装成功
   python3 -c "import flask_socketio; print('Flask-SocketIO安装成功')"
   ```

### 第四步：配置项目

1. **设置文件权限**
   ```bash
   chmod +x start.sh
   chmod +x bt_config.py
   ```

2. **创建数据目录（可选）**
   ```bash
   mkdir -p data
   chmod 755 data
   ```

3. **测试应用**
   ```bash
   python3 app.py
   ```
   如果看到Flask启动信息，说明配置正确

### 第五步：启动服务

1. **在宝塔面板中启动Python项目**
   - 回到宝塔面板 → Python项目
   - 找到刚创建的项目
   - 点击"启动"按钮

2. **或者使用命令行启动**
   ```bash
   cd /www/wwwroot/你的网站目录
   python3 bt_config.py
   ```

3. **设置开机自启（推荐）**
   ```bash
   # 创建systemd服务文件
   sudo nano /etc/systemd/system/jianbing-game.service
   ```

   添加以下内容：
   ```ini
   [Unit]
   Description=Jianbing Poetry Chain Game
   After=network.target
   
   [Service]
   Type=simple
   User=www
   WorkingDirectory=/www/wwwroot/你的网站目录
   ExecStart=/usr/bin/python3 bt_config.py
   Restart=always
   RestartSec=10
   
   [Install]
   WantedBy=multi-user.target
   ```

   启用服务：
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl enable jianbing-game
   sudo systemctl start jianbing-game
   ```

### 第六步：配置反向代理

1. **在宝塔面板中配置网站**
   - 网站 → 设置 → 反向代理
   - 添加反向代理：
     - 代理名称：`jianbing-api`
     - 目标URL：`http://127.0.0.1:5000`
     - 发送域名：`$host`
     - **重要**：启用WebSocket支持

2. **配置WebSocket支持**
   - 在反向代理配置中添加以下参数：
   ```nginx
   proxy_http_version 1.1;
   proxy_set_header Upgrade $http_upgrade;
   proxy_set_header Connection "upgrade";
   proxy_set_header Host $host;
   proxy_set_header X-Real-IP $remote_addr;
   proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
   proxy_set_header X-Forwarded-Proto $scheme;
   ```

3. **配置伪静态（可选）**
   - 网站 → 设置 → 伪静态
   - 选择"自定义"，添加以下规则：
   ```nginx
   location / {
       try_files $uri $uri/ @python;
   }
   
   location @python {
       proxy_pass http://127.0.0.1:5000;
       proxy_http_version 1.1;
       proxy_set_header Upgrade $http_upgrade;
       proxy_set_header Connection "upgrade";
       proxy_set_header Host $host;
       proxy_set_header X-Real-IP $remote_addr;
       proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
       proxy_set_header X-Forwarded-Proto $scheme;
   }
   ```

## 🔧 常见问题解决

### 问题1：Python环境找不到
```bash
# 检查Python安装
which python3
python3 --version

# 如果没安装，手动安装
yum install python3 python3-pip  # CentOS
apt-get install python3 python3-pip  # Ubuntu/Debian
```

### 问题2：依赖安装失败
```bash
# 升级pip
pip3 install --upgrade pip

# 使用国内镜像
pip3 install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple/

# 如果eventlet安装失败，尝试：
pip3 install eventlet==0.33.3
pip3 install Flask-SocketIO==5.3.6
```

### 问题3：端口被占用
```bash
# 检查端口占用
netstat -tlnp | grep :5000

# 杀死占用进程
kill -9 进程ID

# 或者修改端口
# 在app.py中修改端口号
```

### 问题4：权限不足
```bash
# 修改目录权限
chown -R www:www /www/wwwroot/你的网站目录
chmod -R 755 /www/wwwroot/你的网站目录
```

### 问题5：WebSocket连接失败
```bash
# 检查nginx配置是否支持WebSocket
# 确保反向代理配置包含以下内容：
proxy_http_version 1.1;
proxy_set_header Upgrade $http_upgrade;
proxy_set_header Connection "upgrade";

# 检查防火墙是否阻止WebSocket连接
firewall-cmd --list-ports
firewall-cmd --permanent --add-port=5000/tcp
firewall-cmd --reload
```

### 问题6：房间功能异常
```bash
# 检查房间数据文件权限
ls -la rooms_data.json
chmod 644 rooms_data.json
chown www:www rooms_data.json

# 检查内存使用情况
free -h
# 如果内存不足，考虑增加swap空间
```

### 问题5：模板文件找不到 (TemplateNotFound: index.html)
```bash
# 这个错误通常是因为Flask应用找不到templates目录
# 确保项目结构正确，templates目录在项目根目录下

# 检查目录结构
ls -la /www/wwwroot/你的网站目录

# 确保templates和static目录存在且有正确权限
chown -R www:www /www/wwwroot/你的网站目录/templates
chown -R www:www /www/wwwroot/你的网站目录/static
chmod -R 755 /www/wwwroot/你的网站目录/templates
chmod -R 755 /www/wwwroot/你的网站目录/static
```

如果仍然出现模板找不到的问题，可以修改bt_config.py文件，明确指定模板和静态文件路径：

```python
# 在bt_config.py中添加以下代码
import sys

# 添加当前目录到系统路径
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))

# 设置模板和静态文件路径
app.template_folder = os.path.join(os.path.dirname(os.path.abspath(__file__)), 'templates')
app.static_folder = os.path.join(os.path.dirname(os.path.abspath(__file__)), 'static')
```
