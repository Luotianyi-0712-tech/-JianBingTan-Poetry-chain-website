# 固定房间功能测试清单

## 启动前检查

- [ ] 确认所有文件已保存
- [ ] 检查 `app.py` 是否包含固定房间相关代码
- [ ] 检查 `templates/sharedroom.html` 是否存在
- [ ] 检查 `static/sharedroom.css` 是否存在
- [ ] 检查 `static/script.js` 是否包含浮动菜单代码

## 启动服务器

```bash
python app.py
```

预期输出：服务器在 `http://0.0.0.0:5000` 启动

## 测试步骤

### 1. 浮动菜单测试 ✉

#### 1.1 主页面测试
- [ ] 打开 `http://localhost:5000`
- [ ] 注册一个测试用户（例如：测试用户1）
- [ ] 创建或加入一个普通房间
- [ ] 检查右下角是否显示 ✉ 图标的圆形按钮
- [ ] 点击按钮，检查是否从右侧滑出黑色侧边栏
- [ ] 检查侧边栏是否显示5个菜单项
- [ ] 点击 × 按钮，检查侧边栏是否关闭

#### 1.2 菜单项测试
- [ ] 第一项显示 "🏛️ 共享空间"，可点击
- [ ] 第2-5项显示 "🔒 功能X（敬请期待）"，呈灰色不可点击

### 2. 共享空间页面测试

#### 2.1 页面访问
- [ ] 点击"共享空间"菜单项
- [ ] 页面跳转到 `/Sharedroom`
- [ ] 检查页面标题显示 "🏛️ 共享空间"
- [ ] 检查是否显示6个房间卡片

#### 2.2 房间卡片显示
检查每个房间是否正确显示：
- [ ] 100001 - 春之庭 🌸
- [ ] 100002 - 夏之苑 🍃
- [ ] 100003 - 秋之阁 🍂
- [ ] 100004 - 冬之轩 ❄️
- [ ] 100005 - 月之榭 🌙
- [ ] 100006 - 日之台 ☀️

#### 2.3 统计信息
- [ ] 每个房间显示在线人数（👥）
- [ ] 每个房间显示诗词数量（📝）
- [ ] 数字初始应为 0

### 3. 固定房间功能测试

#### 3.1 加入固定房间
- [ ] 点击任意房间的"进入房间"按钮（例如：春之庭）
- [ ] 检查是否跳转回主游戏页面
- [ ] 检查房间码显示是否为 100001
- [ ] 检查是否显示 "🏛️固定" 标识

#### 3.2 普通用户权限测试
使用普通用户（非"管理员"）：
- [ ] 可以正常添加诗词
- [ ] 检查"重置游戏"按钮是否为灰色
- [ ] 检查按钮是否不可点击
- [ ] 鼠标悬停在按钮上，检查是否显示提示
- [ ] 尝试点击按钮，检查是否弹出提示："固定房间只能由管理员重置"

#### 3.3 多用户测试
- [ ] 打开另一个浏览器窗口（或无痕模式）
- [ ] 注册另一个用户（例如：测试用户2）
- [ ] 加入同一个固定房间（100001）
- [ ] 在第一个窗口添加诗词
- [ ] 检查第二个窗口是否实时更新
- [ ] 在共享空间页面检查人数是否增加

### 4. 管理员权限测试

#### 4.1 管理员登录
- [ ] 打开新的浏览器窗口
- [ ] 注册用户名为 "管理员"
- [ ] 加入固定房间 100001

#### 4.2 管理员权限
- [ ] 检查"重置游戏"按钮是否为正常颜色（可点击）
- [ ] 点击"重置游戏"按钮
- [ ] 确认重置操作
- [ ] 检查房间内容是否被清空
- [ ] 检查其他用户窗口是否收到重置通知

#### 4.3 管理员控制台测试
- [ ] 管理员加入房间 207128
- [ ] 检查是否显示所有房间列表
- [ ] 检查固定房间是否标记为 "is_fixed: true"
- [ ] 尝试删除一个固定房间
- [ ] 检查是否提示"固定房间已清空（固定房间不会被删除）"
- [ ] 检查房间是否仍然存在但内容被清空

### 5. 持久化测试

#### 5.1 房间保留测试
- [ ] 在固定房间中添加一些诗词
- [ ] 所有用户离开固定房间
- [ ] 检查房间是否仍然存在（不会被删除）
- [ ] 重新加入房间
- [ ] 检查诗词是否还在

#### 5.2 服务器重启测试
- [ ] 在固定房间中添加诗词
- [ ] 停止服务器（Ctrl+C）
- [ ] 重新启动服务器
- [ ] 检查固定房间是否自动初始化
- [ ] 检查之前的诗词数据是否保留

### 6. 兼容性测试

#### 6.1 普通房间功能
- [ ] 创建一个新的普通房间
- [ ] 检查房间码是否为6位随机数字（非100001-100006）
- [ ] 在普通房间中添加诗词
- [ ] 检查"重置游戏"按钮是否正常可用
- [ ] 点击重置，检查是否成功

#### 6.2 12小时清理机制
注意：此测试需要修改代码或等待12小时
- [ ] 创建一个普通房间
- [ ] 离开房间
- [ ] 等待12小时（或临时修改清理时间为1分钟测试）
- [ ] 检查普通房间是否被清理
- [ ] 检查固定房间是否未被清理

### 7. 响应式测试

#### 7.1 移动端测试
- [ ] 使用手机或浏览器开发者工具切换到移动视图
- [ ] 检查浮动按钮是否显示且大小合适
- [ ] 检查侧边栏宽度是否适配移动端
- [ ] 检查共享空间页面是否响应式布局
- [ ] 检查房间卡片是否垂直排列

#### 7.2 不同浏览器测试
- [ ] Chrome
- [ ] Firefox
- [ ] Safari
- [ ] Edge

### 8. 边界情况测试

#### 8.1 并发测试
- [ ] 多个用户同时加入同一固定房间
- [ ] 多个用户同时添加诗词
- [ ] 检查是否有冲突或错误
